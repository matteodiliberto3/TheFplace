# Regole di Progetto

## Git Remote: Solo thefplace
- Il remote autorizzato ed esclusivo per il push è **sempre e solo `thefplace`** (`https://github.com/matteodiliberto3/TheFplace.git`).
- È vietato effettuare il push su `origin` (`elteo003`).
- Esegui sempre il push puntando a `thefplace` (es. `git push thefplace main`).
